# Evaluation Outputs

This folder contains outputs generated by the capstone experiments.

## Key privacy result

`metrics.json` records the membership-inference attack AUC values:

- Logistic Regression attack AUC: **0.5059**
- Random Forest attack AUC: **0.5041**
- Logistic Regression validation AUC: **0.5122**
- Random Forest validation AUC: **0.5041**

Values close to **0.50** indicate performance near random guessing in this tested setup. This should be interpreted narrowly: it means the evaluated attacks did not show measurable membership leakage under the specific experiment configuration. It does **not** prove immunity to all privacy attacks.

## Other outputs

- `confusion_matrix.png` — held-out linkage classification result for the raw-difference MLP.
- `final_test_predictions_raw_mlp.csv` — per-example predictions from the comparison MLP.
- `attack_per_record.csv` and `attack_per_record_on_target.csv` — per-record attack outputs used in analysis.
- `p_trg_in.npy` and `p_trg_out.npy` — target-model probability arrays for member/non-member analysis.

No raw source data is included in this public repository.
